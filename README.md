# TSC

TSC 콜 인사이트 프로토타입입니다.

- 월별 콜 분석
- 고객사·기계번호별 이력 조회
- 하드웨어·소프트웨어 콜 분류
- 방문 엔지니어 및 현장 조치 내용 조회
- 조회 감사 로그
- CSV 및 XLSX 전체 데이터 업로드
- 로그인 게이트 및 개발용 인증
- 업로드 데이터 영구 저장(SQLite fallback / Supabase 연동)
- 영구 조회 감사 로그
- 동적 기간·월별 KPI와 업로드 검증

현재는 테스트 데이터 기반으로 시작하며, 로그인 후 업로드한 데이터는 서버에 저장됩니다. `supabase_schema.sql`을 실행하고 `.env.example` 값을 환경변수로 설정하면 Supabase를 사용합니다. 설정이 없으면 로컬 SQLite fallback을 사용합니다. XLSX 업로드와 API 저장을 사용하려면 `server.py`로 로컬 서버를 실행합니다.
